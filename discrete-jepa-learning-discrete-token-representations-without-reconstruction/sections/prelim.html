I-JEPA — the direct ancestor of Discrete-JEPA — rests on three components: a context encoder fθc that processes the visible (unmasked) patches, an EMA target encoder fθ̄t whose weights are a slow exponential moving average of the context encoder's weights , and a lightweight predictor gφ that, given the context representations and a set of masked target positions, predicts what the target encoder would output at those locations. The EMA coupling is what prevents representational collapse: the target encoder is a momentum-lagged copy, not a jointly optimized twin, so the gradient cannot trivially make both sides agree by collapsing.

The training signal is an L2 distance in representation space, summed over all masked target positions i ∈ M. Because the loss lives in the encoder's latent space and not in pixel space , the encoder is free to discard low-level texture and retain only the features needed to predict masked context — a property Discrete-JEPA inherits and pushes further by replacing those continuous latents with discrete codebook entries.

Why this matters
Discrete-JEPA only changes the semantic stream — everything below stays. The context encoder, EMA target encoder, predictor, and latent-space L2 loss remain exactly as above; the new work sits on top, quantising the semantic representation into discrete codebook tokens.
