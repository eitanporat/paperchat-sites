Every (Text, Code) pair in a dataset like NL-RX or Spider encodes the same underlying meaning twice — once in natural language, once in a formal language. That redundancy is precisely the signal that JEPA was built to exploit. Vision JEPAs already show that embedding-space prediction outperforms input-space reconstruction for perception tasks; LLM-JEPA ports that idea to language by treating the (Text, Code) split as its two views.

The objective is a sum of two terms. The first is the standard next-token prediction loss, preserving the model's generative capability. The second is a JEPA term — a distance in embedding space between a predicted embedding (derived from Text alone) and the actual embedding of Code. A scalar λ weights their contributions.

Three design choices determine how the two terms are computed. Each is deliberately lightweight: no new modules, no separate optimizer states, no extra parameters beyond the scalar λ and the integer k.

The central implementation challenge is computing Enc(Text) and Enc(Code) without letting either view attend to the other, while still sharing a single forward pass. A naive concatenation would pollute the Code embedding with Text tokens. The solution is a block-causal attention mask: the sequence-length × sequence-length attention matrix is initialized to −∞ everywhere, then two independent lower-triangular causal masks are written — one covering the Text span, one covering the Code span. Each view attends only within itself.

With this mask in place, both embeddings are available after two forward passes instead of three — one pass over the concatenated (Text ‖ Code) context with the block-causal mask, and one pass over (Text ‖ [PRED]×k) for the predictor. The extra cost during training does not appear at inference, because the JEPA term is not needed once the model is deployed. A loss-dropout strategy (covered in §5.2) reduces that overhead further by skipping the JEPA term for a random fraction of mini-batches.

Core mechanism
LLM-JEPA adds a single embedding-space term to the standard next-token loss: predict Enc(Code) from Enc(Text) using the model's own weights as the predictor. A block-causal attention mask makes both embeddings computable in two forward passes, with no new parameters and no change to the inference graph.
