The JEPA loss sculpts a near-linear geometry between Text and Code embeddings — a structural signature absent from both the base model and the standard NTP fine-tune. Two diagnostics make this concrete: a t-SNE projection and a singular-value decomposition of Enc(Text) − Enc(Code).

The four-panel t-SNE in Figure 6 tells the story before any numbers do: the base model has weak but non-zero Text/Code cluster structure; standard NTP fine-tuning shatters it; both LLM-JEPA variants recover tight, paired clusters where each Text point sits beside its Code counterpart.

The quantitative signal mirrors the picture. Fit a linear map X that minimises ‖Enc(Text)·X − Enc(Code)‖ on the four conditions and the residual collapses by three orders of magnitude under LLM-JEPA, with the top-100 singular values of the residual matrix following the same drop — i.e., what's left after the linear fit is confined to a narrow subspace.

This near-linearity may be why LLM-JEPA generalises well: once Text and Code embeddings are related by a simple affine map, the model's decoder has an easy path from a natural-language prompt to the correct code structure. Accuracy follows geometry.

Three takeaways stand out from the table above. First, the distance metric is load-bearing: ℓ2 doesn't just underperform — it triggers full dimensional collapse, the same pathology documented in contrastive learning. MSE survives but cosine wins narrowly, and cosine is the vision-JEPA default. Second, appending [PRED] beats prepending — the autoregressive stack has processed the full Text context by the last position, so that's where the predictor embedding belongs. Third, Text→Code is the natural direction: asking the model to predict the structured output's embedding from a natural-language query aligns with the generative task. InfoNCE at the standard temperature τ=0.07 fails outright, with several-times larger variance — its in-batch negative sampling pressure is mis-calibrated for this asymmetric one-to-one task.

Takeaway
Cosine distance, an appended [PRED] token, and the Text→Code direction are the right recipe — each choice is load-bearing. The gain is not incidental: the JEPA loss reshapes the entire embedding geometry into a near-linear, low-rank mapping between natural language and code, and that structure is what drives downstream accuracy.
