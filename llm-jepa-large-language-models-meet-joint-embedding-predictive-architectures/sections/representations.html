The JEPA loss sculpts a near-linear geometry between Text and Code embeddings — a structural signature absent from both the base model and the standard NTP fine-tune. Two diagnostics make this concrete: a t-SNE projection and a singular-value decomposition of Enc(Text) − Enc(Code).

t-SNE plots of the four conditions (base model, NTP fine-tune, LLM-JEPA k=0, LLM-JEPA k=1) tell a clear story: the base model has weak but non-zero cluster structure; NTP fine-tuning shatters it — Text and Code points intermix without pattern; both LLM-JEPA variants recover tight, paired clusters where each text point sits beside its code counterpart (Figure 6, appendix). The quantitative signal comes from fitting a linear map X that minimises ‖Enc(Text)·X − Enc(Code)‖. Under NTP fine-tuning the residual sits at 3 035 — barely lower than the untrained base model's 3 053. LLM-JEPA collapses it to 4.47 (k=0) or 4.04 (k=1): a three-order-of-magnitude drop. The top-100 singular values of the residual matrix fall from ~341 down to ~17, meaning the residual is confined to a narrow subspace.

This near-linearity may be why LLM-JEPA generalises well: once Text and Code embeddings are related by a simple affine map, the model's decoder has an easy path from a natural-language prompt to the correct code structure. Accuracy follows geometry.

Three design choices stand out. First, the distance metric is load-bearing: the ℓ2 norm catastrophically collapses representations to 2.22% accuracy, echoing dimensional-collapse pathologies documented in contrastive learning. MSE recovers (70.64%), but cosine edges it out and is the standard in vision JEPAs. Second, appending [PRED] beats prepending (71.46% vs 68.07%) — the autoregressive stack has already processed the full context before producing the predictor embedding, so the last position carries more. Third, Text→Code is the natural direction (71.46% vs 65.70%): asking the model to predict the structured output's embedding from the natural-language query aligns with the generative task. InfoNCE at the standard temperature τ=0.07 performs worse than even the baseline, with variance three to four times larger — the in-batch negative sampling pressure is mis-calibrated for this asymmetric task.

The hyperparameter surface (λ, k) ∈ {0.5, 1, 2, 4} × {0, 1, 2, 3, 4} is smooth enough to navigate by grid search, though no single corner dominates across all model–dataset pairs. Takeaway
Cosine distance, an appended [PRED] token, and the Text→Code direction are the right recipe — each choice is load-bearing. The gain is not incidental: the JEPA loss reshapes the entire embedding geometry into a near-linear, low-rank mapping between natural language and code, and that structure is what drives downstream accuracy.
