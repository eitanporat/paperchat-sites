§4.3 · lifelong learning
pp. 8–9

A household robot never gets to stop learning. Instead of the tidy pretrain-then-finetune split, lifelong learning strings tasks into a sequence of phases and asks the harder question: can new skills be acquired without erasing the old ones?

The benchmark runs four phases of steadily growing horizon, where a stage is a single robot-skill invocation. Each phase adds a fresh batch of tasks and never revisits the earlier ones.

Training is strictly sequential: for phase N, take the phase N−1 model and fine-tune only on phase-N data, then evaluate every task from phases 1…N back in the pretraining kitchens. The scoreboard below is that evaluation — a lower-triangular grid of success rates.

Two failures fall out of the same numbers. Read down the diagonal — the tasks each phase just learned — and success collapses 41.5 → 24.5 → 11.3 → 4.3 as the horizon grows: longer tasks simply demand more data than a fixed 20-demo-per-task budget provides.

Read instead down the atomic column — the very first skills, re-tested after each new phase — and they rot 41.5 → 13.9 → 13.9 → 10.6 without ever being retrained. That is catastrophic forgetting: skill on old tasks decays the moment the model stops practising them.

Takeaway
Sequential fine-tuning gets squeezed from both ends — new long-horizon tasks are harder to pick up while old ones quietly fade — which is exactly why lifelong learning stays an open problem and a useful testbed rather than a solved step.
